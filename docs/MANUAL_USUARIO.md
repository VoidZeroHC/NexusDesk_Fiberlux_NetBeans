# Guía rápida de funcionamiento

**1. Inicio de sesión.** Seleccione Cliente, Técnico NOC o Administrador en las pestañas. El perfil de prueba rellena el usuario y contraseña; seleccione «Ingresar al portal».

**2. Dashboard NOC.** Consulte tickets abiertos, en riesgo de SLA, resueltos y porcentaje de cumplimiento. Las cifras se calculan desde la base de datos; pulse actualizar para refrescarlas.

**3. Crear un ticket.** El cliente selecciona la categoría y prioridad, introduce título, descripción, circuito, servicio y sede. Puede adjuntar un JPG, PNG, PDF o TXT hasta 2 MB. El backend genera código FLX y asigna al técnico disponible.

**4. Tablero Kanban.** Filtre por código, categoría, prioridad o cliente. Abra un ticket pulsando «Detalle».

**5. Detalle y seguimiento.** Consulte SLA y tiempo restante, evidencias, auditoría y comentarios. El técnico asignado o el administrador puede modificar el estado. El administrador puede reasignar. Al resolverse, el cliente confirma conformidad para cerrar.

**6. Usuarios y roles.** El administrador puede crear perfiles Cliente, Técnico y Administrador, desactivar/reactivar cuentas y buscar personas.

**7. Reportes.** El administrador consulta reportes completos, el técnico sus indicadores personales. Use filtros de periodo o profesional y descargue Excel/PDF.

**8. Cerrar sesión.** Pulse el símbolo de salida en la barra superior.
